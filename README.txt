Game Character Hub drop-in files

Files:
- index.html
- characters/index.html
- style.css
- script.js
- worker.js
- assets/placeholder.png

Deploy the front-end folder to Cloudflare Pages.

Deploy worker.js as:
https://gamehub.crysthigpen.workers.dev

Cloudflare Worker variables/secrets needed:
- NOTION_TOKEN
- NOTION_DATABASE_ID

Notion properties:
- Name
- Owner
- Age
- Race
- Partner
- Game
- Portrait
- Gallery
- NSFW Gallery
- Dumb Screenshots
- Slug (optional)

Owner should be Luna or Star.
